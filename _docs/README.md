# _docs

Дополнительные файлы проекта. Не собирается в мод (исключено в `build.yml`).

Сюда кладём:
- декомпилированные архивы других модов (например `_docs/littletiles/`, `_docs/mtr/`);
- исходники для связок с другими модами;
- медиа для ptm2;
- текстовые заметки владельца.

Рекомендуется складывать каждый мод в свою подпапку и не заливать огромные архивы целиком, если можно положить только нужные пакеты.
