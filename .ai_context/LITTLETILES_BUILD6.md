# LittleTiles: сборка 6 (продолжение LITTLETILES_BUILD5.md)

## Что показала проверка сборки 5
- Линия ptm2 на наклонных плитках теперь видна (родной рендерер блока-сущности).
- Проблема 1: пропуски на подъёме (между плитками нет зелёного контура).
- Проблема 2: на дорожном блоке с ямкой/бугорком из миниблоков линия занимает только самую низкую точку, а не идёт по верхушкам всех миниблоков.
- Приложенные логи ничего не добавили: серверный без ошибок, `latest_1.log` — клиент другой сборки (1.12.2, Valkyrien Skies).

## Причины и решения (сборка 6, в игре не проверено)
- Пропуски: ячейка плитки выбиралась по высоте поверхности в центре, а на крутом подъёме верхний край поверхности заходит в ячейку над ней; она занята миниблоком, `canPlace` ложен, ячейка пропускалась. Теперь для наклонных ячеек ячейка берётся над самой высокой точкой (`yc + |slope|*(|fx|+|fz|)/2`), а если занята — пробуется ячейка выше (смещение/высоты корректируются на -1).
- Ямки/бугорки: плитка может быть разбита на SUB=8 кусочков вдоль направления линии. `SlopedMarkingBlockEntity.hs` (float[8], относительно низа ячейки, NBT: int-массив `hs` x256). `LittleBridge.sampleAlong(level, cx, cz, rot, fromY)` берёт 8 отсчётов `topAt` вдоль направления через центр ячейки (до 4 ячеек вниз), отсчёты остаются внутри ячейки. Если в ячейке нет наклонных частей и поверхность найдена: ячейка = над максимумом, наклон 0, при разнице высот <0.02 — одна высота `off`, иначе массив `hs`.
- Рендер (`SlopedMarkingRenderer.drawPieces`): соседние отсчёты одной высоты склеиваются в кусок; кусок = родной рендерер линии, растянутый вдоль направления в долю куска и сдвинутый по направлению, на своей высоте. Вертикальные стенки ямок не рисуются (между кусками на разных высотах остаётся разрыв). Для блоков без блок-сущности (стрелки и т.п.) при `hs` рисуется цельная плитка на высоте середины.
- Ручная постановка (`LittleBridge.onMarkingPlaced`) использует те же отсчёты: если сверху ячейки ровно по всей линии — блок остаётся обычным; иначе заменяется на наклонную плитку с одной высотой или с `hs`. Условия отказа: наклонные части в ячейке, нет поверхности в каком-то отсчёте, перепад больше допустимого.
- В итоговом сообщении карандаша: «по миниблокам N (кусками M)».

## Что проверить
- Исчезли ли пропуски на подъёме (сколько «пропущено»).
- Ямка: идёт ли линия по верху миниблоков вокруг ямки и по дну; видны ли разрывы на стенках.
- Бугорок.
- Стыковка кусков и обычных блоков по краям ячейки.
