# .ai_context — переезд в новый чат

Папка для ИИ-ассистента. Не собирается в мод (исключена в `.github/workflows/build.yml`, `paths-ignore`).

## Как продолжить в новом чате
1. Прочитать по порядку: `PROJECT.md` -> `RULES.md` -> `STATE.md`.
2. Посмотреть корень репозитория и `board/` (актуальные исходники).
3. Дополнительные материалы (декомпиляции модов, заметки владельца) лежат в `_docs/`.
4. Не спрашивать у владельца то, что уже записано здесь.

## Как обновлять
- После каждой завершённой задачи обновить `STATE.md` (сделано / открыто / следующее) и дату сборки.
- Новые решения и договорённости — в `RULES.md`.
- Если чат тормозит — сначала обновить эти файлы, потом переезжать.
