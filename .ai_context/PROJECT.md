# Проект: доработка Public Transport Mod 2 (PTM2)

- Мод: Public Transport Mod 2 (ptm2) 0.6.6.1, Forge 1.20.1, автор оригинала RInventor.
- Исходников у автора нет: работа идёт по декомпиляции jar + патч готового jar.
- Платформа: только Forge. Сервер выделенный (Arclight). Клиент: PojavLauncher (телефон), тесты прямо в игре, сборка через браузер/GitHub Actions.
- Язык общения и интерфейса: русский.

## Главная цель
Рабочий автоматический транспорт по расписанию (автобусы, троллейбусы и т.д.), такси, банк и экономика вокруг этого.

## Структура репозитория
- `PtmFixes.java` — основной код исправлений (копируется в `com.rinventor.ptm2.fixes`).
- `board/*.java` — табло направлений по полосам (копируется в `com.rinventor.ptm2.fixes.board`).
- `Patcher.java` — ASM-патчер: накладывает `fixes.jar` на оригинальный jar.
- `ru_ru.json` — русский перевод (кладётся в `assets/ptm2/lang/`).
- `extra-assets.zip` — дополнительные ассеты (модели/текстуры, напр. `lane_board_*`).
- `.github/workflows/build.yml` — сборка.

## Как идёт сборка (build.yml)
1. Скачивается оригинальный jar из релиза `base`.
2. Gradle (ForgeGradle 6, Forge 1.20.1-47.4.0, Java 17) компилирует `PtmFixes.java` + `board/*.java` против оригинального jar (`compileOnly`).
3. `Patcher` (ASM 9.6) вшивает исправления в оригинальный jar -> `out/ptm2-patched.jar`.
4. Добавляются `ru_ru.json` и `extra-assets.zip`.
5. Публикуется релиз `build-<номер>`.
Изменения только в `_docs/**` и `.ai_context/**` сборку не запускают.

## Принципы
- Решения универсальные для любой карты: город растёт и меняется, чинить по координатам нельзя — только корень проблемы.
- ptm2 — ядро для интеграций с другими модами, но каждый мод должен работать и без остальных; при наличии — мягкая подхватка (soft dependency).
- Логику при игре на сервере считает сервер, клиент только рисует (нужно избегать рассинхронизации и лагов отображения при нескольких игроках).
- Не ломать работающее: перестроения/ИИ движения не трогать без запроса.
